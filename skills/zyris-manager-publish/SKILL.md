# Publish a plugin

Read `../zyris-skill-manager/SKILL.md` and its `references/publish.md` before acting. This capability belongs to the single ZYRIS Skill Manager plugin. Follow the **publish** routing and the mandatory approval boundary. A request to implement or prepare publish is not authorization to commit or publish. Use the bundled `../zyris-skill-manager/scripts/publish_plan.py` for the immutable local plan and progress journal. Do not require a Manager source checkout.
